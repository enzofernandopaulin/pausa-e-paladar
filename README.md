# Pausa e Paladar — Cestas & tábuas artesanais

Página institucional da Pausa e Paladar, uma marca autoral de cestas de café da manhã, tábuas com doces, pães e outros presentes montados à mão.

## Stack

React + TypeScript + Tailwind v4 + TanStack Start / Vite.

## Instalar e executar

```bash
bun install
bun run dev
```

Também é possível usar `npm install` e `npm run dev`.

## Build e validação

```bash
bun run build
bun run lint
bun run test
```

## Conteúdo editável

- Textos e seções: `src/routes/index.tsx`
- Cores, fontes e componentes visuais: `src/styles.css`
- Logotipo: `src/components/Logo.tsx`
- Imagem da cesta: `src/assets/gift_basket.jpg`

Os canais de Instagram e contato estão apresentados como pontos de edição no rodapé. Substitua pelos canais oficiais antes de publicar.
